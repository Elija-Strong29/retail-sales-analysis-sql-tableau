Retail Sales Analysis Using SQL & Tableau

Project Overview
This project analyzes sales transactions from April 2019 using SQL and Tableau. The goal was to answer business questions about revenue, product performance, customer purchases, order patterns, and location.

Tools Used
- MySQL
- Tableau
- Google Docs

SQL Skills Used
- Aggregate Functions
- GROUP BY and ORDER BY
- Date Functions
- String Functions
- Subqueries
- Self Joins
- CASE Statements

Key Findings
- Total revenue for April was $3,396,059.11 across 17,537 unique orders.
- The MacBook Pro Laptop generated the most revenue at $773,500.
- AAA Batteries (4-pack) sold the most units with 2,936 units sold.
- 7 PM had the highest number of orders with 1,225 unique orders.
- April 24 generated the most daily revenue at $136,177.32.
- San Francisco generated the most revenue at $817,074.77.
- Average revenue per order was $193.65.
- Smartphones were frequently purchased with related accessories such as charging cables and headphones.
- Most orders were classified as Small, with 10,801 orders under $100.
